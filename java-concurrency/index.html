Как работать с пособием

  1. Прочитайте страницу целиком один раз, не останавливаясь на деталях. Задача — увидеть картину.
  2. Перепишите каждый пример руками в IDE (не копируйте) и запустите. Поменяйте одну вещь — уберите volatile, поменяйте порядок локов — и предскажите результат до запуска.
  3. Ответьте вслух на вопросы для самопроверки, затем раскройте ответ. Расхождения — повод перечитать раздел.
  4. Объясните пример «четырьмя вопросами» из темы 12: какие потоки, какие общие изменяемые данные, какая синхронизация даёт happens-before, что будет при отказе/перегрузке.
  5. Отметьте тему изученной внизу страницы — прогресс виден слева.
Версии Java Основа — JDK 17/21 (LTS), всё, что специфично для новых версий, помечено. Виртуальные потоки финальны с JDK 21; начиная с JDK 24 synchronized больше не «пришпиливает» виртуальный поток к carrier (JEP 491); ScopedValue финален в JDK 25, Structured Concurrency в JDK 25 ещё preview.
