Битовые операции

Битовые операции работают с отдельными битами числа и дают O(1)-приёмы, которые иначе требовали бы циклов. Распознаётся по «только один раз встречается», «счёт единичных битов», «все подмножества», «степень двойки». Ядро — свойства XOR и сдвигов.

17.2Счёт единичных битов

int popcount(int x) {
    int c = 0;
    while (x != 0) { x = x & (x - 1); c++; }   // сбрасываем по одному биту
    return c;
}

17.3Одиночное число (XOR)

XOR числа с самим собой даёт 0, а с 0 — само число. Поэтому XOR всех элементов оставляет только тот, что встречается нечётное число раз.

int singleNumber(int[] a) {
    int r = 0;
    for (int x : a) r ^= x;   // парные взаимно уничтожаются
    return r;
}

17.4Подмножества битовыми масками

Подмножество из n элементов кодируется числом от 0 до 2ⁿ−1: бит i = 1, если i-й элемент входит.

for (int mask = 0; mask < (1 << n); mask++) {
    for (int i = 0; i < n; i++)
        if ((mask & (1 << i)) != 0) {
            // элемент i входит в подмножество mask
        }
}

17.5Самопроверка

Что делает x & (x - 1)?

  • Сбрасывает младший единичный бит
  • Устанавливает младший бит
  • Умножает на 2
  • Инвертирует
Классический трюк для счёта битов и проверки степени двойки.

Почему XOR всех элементов даёт одиночное число?

  • x ^ x = 0 и x ^ 0 = x, парные сокращаются
  • XOR складывает
  • XOR сортирует
  • Случайность
Коммутативность и ассоциативность XOR сокращают все пары.

Сколько подмножеств кодируется масками от 0 до 2ⁿ−1?

  • n
  • n²
  • 2ⁿ
  • log n
Каждый из n элементов либо входит, либо нет — 2ⁿ вариантов.

Как проверить, является ли число степенью двойки?

  • x > 0 && (x & (x - 1)) == 0
  • x % 2 == 0
  • x > 2
  • x ^ 1
У степени двойки один единичный бит; его сброс даёт 0.
Чем отличается >> от >>> в Java?

>> — арифметический сдвиг (сохраняет знак, заполняя старший бит), >>> — логический (заполняет нулями). Для отрицательных чисел результаты различаются.

Как сгенерировать все подмаски данной маски?

Циклом for (int s = mask; s > 0; s = (s - 1) & mask) — перебирает все подмножества битов маски.
