Префиксные суммы — простыми словами

Если нужно много раз узнавать сумму на разных отрезках, не складывайте каждый раз заново. Заведите «нарастающий итог» — и любая сумма отрезка станет одним вычитанием. Тот же приём с таблицей помогает считать отрезки с нужной суммой, а «разностный массив» — быстро прибавлять к целым отрезкам.

9.1Нарастающий итог: тетрадка расходов

Вы записываете траты за каждый день. А рядом ведёте вторую колонку — «всего потрачено с начала месяца». Сколько вы потратили с 10-го по 20-е? Не нужно складывать 11 чисел: «всего к 20-му» минус «всего к 9-му». Одно вычитание!

День12345
Трата31415
Всего с начала348914

Траты со 2-го по 4-й: «всего к 4-му» (9) минус «всего к 1-му» (3) = 6. Проверка: 1 + 4 + 1 = 6 ✓.

Колонку «всего с начала» называют префиксными суммами. Её строят один раз за O(n), а потом каждый вопрос «сумма на отрезке?» — мгновенно, O(1).

Главная мысль Сумма отрезка = итог к концу отрезка минус итог перед его началом.

9.2Сколько отрезков дают нужную сумму

Задача: сколько отрезков подряд имеют сумму ровно k? Числа могут быть отрицательными, поэтому окно из главы 03 не работает.

Используем то, что знаем: сумма отрезка = итог сейчас − итог когда-то раньше. Мы хотим, чтобы это равнялось k. Значит, для текущего итога нужно знать, сколько раз раньше встречался итог «текущий минус k». А «сколько раз встречалось» — это работа для хэш-таблицы из главы 05!

Числа [1, 2, 1, −1, 2], ищем отрезки с суммой 3
в таблице: {итог 0: 1 раз}   (пустое начало)
число 1 → итог 1, ищем 1−3=−2 → 0 разчисло 2 → итог 3, ищем 0 → 1 раз ✓  (отрезок [1, 2])число 1 → итог 4, ищем 1 → 1 раз ✓  (отрезок [2, 1])число −1 → итог 3, ищем 0 → 1 раз ✓  (отрезок [1, 2, 1, −1])число 2 → итог 5, ищем 2 → 0 раз
ответ: 3 отрезка

Итог 0 «встречался» один раз — до первого числа. Это нужно, чтобы считать отрезки от самого начала.

Раньше был итог 0, значит, отрезок между ними имеет сумму 3.

Ищем итог 1 — он был после первого числа. Отрезок [2, 1].

Опять ищем 0 — находим отрезок с самого начала.

Один проход, таблица итогов. O(n) вместо перебора всех отрезков.

Главная мысль Префиксные суммы + хэш-таблица = подсчёт отрезков с нужной суммой за один проход, даже с отрицательными числами.

9.3Разностный массив: прибавить к целому отрезку

Обратная задача: много раз «прибавь 5 ко всем дням с 3-го по 7-й», а в конце покажи, что получилось. Прибавлять к каждому дню — долго.

Хитрость: ставим только две пометки — «с 3-го дня +5» и «с 8-го дня −5». Как табличка на дороге «начало зоны ремонта» и «конец зоны». А в самом конце один раз проходим и считаем нарастающий итог пометок — он и даст, сколько добавилось к каждому дню.

Главная мысль Разностный массив: две пометки на отрезок вместо прибавления к каждому дню, итог — одним проходом в конце.

9.5Проверьте себя

Итог к 20-му дню — 500, к 9-му — 200. Сколько потрачено с 10-го по 20-е?

  • 700
  • 200
  • 300
  • нельзя узнать
500 − 200 = 300.

Зачем строить префиксные суммы, если можно просто сложить отрезок?

  • если вопросов много, каждый ответ становится одним вычитанием
  • чтобы сэкономить память
  • чтобы отсортировать данные
  • это не нужно никогда
Строим один раз за O(n), а каждый из тысячи вопросов — за O(1).

Почему для «отрезков с суммой k» с отрицательными числами не подходит окно?

  • окно не умеет складывать
  • окно работает только со строками
  • отрицательные числа запрещены
  • с минусами добавление элемента не всегда увеличивает сумму, и непонятно, когда сжимать окно
Поэтому используют префиксы и таблицу «сколько раз встречался такой итог».

Зачем в таблице заранее записать «итог 0 — один раз»?

  • чтобы таблица не была пустой
  • чтобы учитывать отрезки, которые начинаются с самого первого элемента
  • для красоты
  • чтобы избежать ошибки деления на ноль
Отрезок от начала — это «итог сейчас минус итог до начала», а он равен нулю.

Нужно 1000 раз прибавить числа к разным отрезкам. Что делает разностный массив?

  • прибавляет к каждому элементу отрезка
  • сортирует отрезки
  • ставит по две пометки на отрезок и в конце один раз считает итог
  • удаляет отрезки
Две пометки — O(1) на отрезок, плюс один проход в конце.
