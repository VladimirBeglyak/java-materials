Связанный список

Связанный список почти всегда решается двумя приёмами: указатели fast/slow (цикл, середина) и аккуратная работа с указателями next (разворот, удаление). Фиктивный (dummy) узел убирает кучу крайних случаев с головой списка.

8.1Поиск цикла (Floyd)

Медленный указатель шагает на 1, быстрый — на 2. Если они встретились — цикл есть. Точку начала цикла находят вторым проходом.

boolean hasCycle(ListNode head) {
    ListNode slow = head, fast = head;
    while (fast != null && fast.next != null) {
        slow = slow.next;
        fast = fast.next.next;
        if (slow == fast) return true;   // встретились — цикл
    }
    return false;
}

8.2Середина списка

Когда быстрый доходит до конца, медленный — на середине.

ListNode middle(ListNode head) {
    ListNode slow = head, fast = head;
    while (fast != null && fast.next != null) {
        slow = slow.next;
        fast = fast.next.next;
    }
    return slow;   // середина (для чётной длины — вторая половина)
}

8.3Разворот списка

ListNode reverse(ListNode head) {
    ListNode prev = null, cur = head;
    while (cur != null) {
        ListNode next = cur.next;   // запомнить
        cur.next = prev;            // развернуть ссылку
        prev = cur;
        cur = next;
    }
    return prev;                    // новая голова
}

8.4Удаление n-го с конца

Два указателя с разницей n: первый уходит вперёд на n шагов, затем оба шагают вместе; когда первый у конца, второй — перед удаляемым. Dummy-узел упрощает случай удаления головы.

ListNode removeNthFromEnd(ListNode head, int n) {
    ListNode dummy = new ListNode(0, head);
    ListNode fast = dummy, slow = dummy;
    for (int i = 0; i <= n; i++) fast = fast.next;   // отрыв на n+1
    while (fast != null) { fast = fast.next; slow = slow.next; }
    slow.next = slow.next.next;                      // пропустить удаляемый
    return dummy.next;
}

8.5Самопроверка

Как обнаружить цикл в списке?

  • Хэш-таблицей всех узлов
  • Указателями fast/slow (Floyd) за O(1) памяти
  • Сортировкой
  • Двоичным поиском
fast шагает вдвое быстрее; встреча = цикл. Хэш-таблица тоже работает, но O(n) памяти.

Когда медленный указатель оказывается на середине?

  • Когда быстрый доходит до конца
  • Сразу
  • Через n шагов
  • Никогда
fast движется вдвое быстрее, поэтому когда он в конце, slow — на середине.

Зачем dummy-узел при удалении n-го с конца?

  • Ускорить
  • Сэкономить память
  • Упростить случай удаления головы списка
  • Он обязателен всегда
Dummy перед головой убирает отдельную ветку «удаляем первый элемент».

Какая сложность разворота списка?

  • O(n) времени, O(1) памяти
  • O(n²)
  • O(n) времени, O(n) памяти
  • O(log n)
Один проход, переставляя ссылки на месте.
Как найти точку начала цикла, а не только факт цикла?

После встречи slow/fast вернуть один указатель на голову и двигать оба с шагом 1; их новая встреча — начало цикла (свойство расстояний Флойда).

Назовите два главных приёма для связанных списков.

Fast/slow указатели (цикл, середина, n-й с конца) и аккуратная перестановка ссылок next (разворот, удаление, вставка), часто с dummy-узлом.
