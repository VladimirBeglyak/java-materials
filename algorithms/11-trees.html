Деревья: обходы и BST

Деревья почти всегда обходят рекурсивно: pre-order (корень → лево → право), in-order (лево → корень → право), post-order (лево → право → корень). Выбор обхода зависит от задачи: in-order даёт отсортированный порядок в BST, post-order — обработку детей до родителя. BFS по уровням нужен для «по уровням» и «ближайший».

11.1Обходы

void preorder(Node n) { if (n == null) return; visit(n); preorder(n.left); preorder(n.right); }
void inorder(Node n)  { if (n == null) return; inorder(n.left); visit(n); inorder(n.right); }
void postorder(Node n){ if (n == null) return; postorder(n.left); postorder(n.right); visit(n); }

11.2BFS по уровням

List<List<Integer>> levelOrder(Node root) {
    List<List<Integer>> res = new ArrayList<>();
    if (root == null) return res;
    Deque<Node> q = new ArrayDeque<>();
    q.add(root);
    while (!q.isEmpty()) {
        int size = q.size();                 // число узлов текущего уровня
        List<Integer> level = new ArrayList<>();
        for (int i = 0; i < size; i++) {
            Node n = q.poll();
            level.add(n.val);
            if (n.left != null) q.add(n.left);
            if (n.right != null) q.add(n.right);
        }
        res.add(level);
    }
    return res;
}

11.3Глубина и симметрия

int depth(Node n) {
    if (n == null) return 0;
    return 1 + Math.max(depth(n.left), depth(n.right));
}

11.4BST: проверка и поиск

В бинарном дереве поиска левое поддерево меньше корня, правое — больше. Проверку делают с диапазоном [min, max].

boolean isValidBST(Node n, long min, long max) {
    if (n == null) return true;
    if (n.val <= min || n.val >= max) return false;
    return isValidBST(n.left, min, n.val) && isValidBST(n.right, n.val, max);
}

11.5Самопроверка

Какой обход даёт отсортированный порядок в BST?

  • pre-order
  • in-order
  • post-order
  • BFS
in-order: левое поддерево → корень → правое = возрастающий порядок.

Какой обход нужен для «обработать детей до родителя»?

  • post-order
  • pre-order
  • in-order
  • level-order
Post-order посещает детей раньше родителя — для высоты, сумм поддеревьев, удаления.

Как разбить BFS по уровням?

  • Запомнить размер очереди до обработки уровня
  • Рекурсией
  • Сортируя узлы
  • Нельзя
size = текущая длина очереди = число узлов уровня; обрабатываем ровно size.

Почему проверку BST делают с диапазоном [min, max]?

  • Для скорости
  • Недостаточно сравнить узел только с детьми — нужно ограничение всего поддерева
  • Чтобы экономить память
  • Это не обязательно
Каждый узел должен лежать между всеми предками; диапазон передаёт эти ограничения.
Как сериализовать и восстановить дерево?

pre-order с маркером NULL: записываем корень, затем левое и правое поддеревья; пустые — спецсимволом. Восстановление — рекурсивно в том же pre-order.

Чем дерево отличается от графа в контексте обходов?

У дерева нет циклов и один корень, поэтому обход не требует отметок «посещён». У графа нужен visited, чтобы не зациклиться (тема 12).
