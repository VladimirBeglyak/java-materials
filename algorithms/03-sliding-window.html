Скользящее окно

Скользящее окно обрабатывает подмассивы/подстроки без пересчёта всего окна заново: поддерживая текущую сумму/состояние, вы «сдвигаете» окно за O(n) вместо O(n·k). Распознаётся по фразам «найти подмассив/подстроку, удовлетворяющий условию», «максимальная сумма k подряд», «самая длинная подстрока без повторений».

3.1Окно фиксированной длины

Окно всегда размера k. Первый шаг — посчитать сумму первых k элементов, дальше сдвигать: вычесть уходящий слева, прибавить входящий справа.

int maxSum(int[] a, int k) {
    int sum = 0;
    for (int i = 0; i < k; i++) sum += a[i];   // первое окно
    int max = sum;
    for (int i = k; i < a.length; i++) {
        sum += a[i] - a[i - k];               // сдвиг окна
        max = Math.max(max, sum);
    }
    return max;
}

3.2Окно переменной длины

Окно растёт и сжимается, пока выполняется условие. Шаблон: правый указатель расширяет, левый сжимает при нарушении условия.

int lengthOfLongestSubstring(String s) {
    Set<Character> seen = new HashSet<>();
    int l = 0, max = 0;
    for (int r = 0; r < s.length(); r++) {
        while (seen.contains(s.charAt(r))) {   // условие нарушено — сжимаем слева
            seen.remove(s.charAt(l++));
        }
        seen.add(s.charAt(r));
        max = Math.max(max, r - l + 1);
    }
    return max;
}
Минимальная длина окна Если ищут минимальную длину при условии «сумма ≥ X», окно сжимают, пока условие ещё выполняется: while (sum >= X) { max = min(max, r-l+1); sum -= a[l++]; }.

3.4Самопроверка

Какая сложность скользящего окна вместо пересчёта каждого подмассива?

  • O(n·k)
  • O(n)
  • O(n²)
  • O(k²)
Окно сдвигается за O(1) на шаг (вычесть ушедший, прибавить вошедший) — суммарно O(n).

Как сдвинуть окно фиксированной длины k на один шаг?

  • sum += a[i] - a[i-k]
  • пересчитать сумму заново
  • sum = a[i]
  • sum -= k
Вычесть элемент, вышедший слева (a[i-k]), прибавить вошедший справа (a[i]).

Когда сжимают окно переменной длины?

  • Когда условие нарушено (пока снова не выполнится)
  • Всегда после каждого шага
  • Только в конце
  • Никогда
Левый указатель сжимает окно, пока не восстановится инвариант (например, нет повторяющихся символов).

Задачу «максимальная сумма k подряд» решает…

  • Окно переменной длины
  • Двоичный поиск
  • Хэш-таблица
  • Окно фиксированной длины
k фиксировано — это окно фиксированной длины.
Как найти «ровно k различных символов в подстроке»?

Через разность двух окон: (число подстрок с ≤ k разными) − (число с ≤ k−1 разными). Каждое «≤ k» считается переменным окном с хэш-таблицей частот.

В чём разница между поиском максимальной и минимальной длины окна?

Для максимума окно расширяют и сжимают только при нарушении условия; для минимума при выполнении условия сжимают слева, фиксируя каждый валидный размер, пока условие держится.
