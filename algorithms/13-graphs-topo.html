Графы: топологическая сортировка и кратчайший путь

Топологическая сортировка упорядочивает вершины ориентированного ациклического графа так, что все рёбра идут «слева направо», — это про зависимости (курсы, сборка, задачи). Кратчайший путь с весами решает алгоритм Дейкстры. Обе — обязательные темы senior-собеседований.

13.1Топологическая сортировка (Kahn)

Считаем входящие степени, кладём в очередь вершины со степенью 0, по очереди «убираем» их, уменьшая степени соседей.

int[] topoSort(int n, List<List<Integer>> adj) {
    int[] indegree = new int[n];
    for (var list : adj) for (int u : list) indegree[u]++;
    Deque<Integer> q = new ArrayDeque<>();
    for (int i = 0; i < n; i++) if (indegree[i] == 0) q.add(i);
    int[] order = new int[n]; int k = 0;
    while (!q.isEmpty()) {
        int v = q.poll();
        order[k++] = v;
        for (int u : adj.get(v)) if (--indegree[u] == 0) q.add(u);
    }
    return k == n ? order : new int[0];   // пусто, если есть цикл
}

13.2Обнаружение цикла

Если после Kahn обработано меньше n вершин — в графе есть цикл (зависимости противоречивы). Классика — «можно ли пройти все курсы» (Course Schedule).

Два способа найти цикл Kahn (число обработанных < n) или DFS с тремя состояниями (0 — не посещён, 1 — в текущем пути, 2 — обработан): встретили состояние 1 — цикл.

13.3Dijkstra

Кратчайший путь от одной вершины до всех в графе с неотрицательными весами: min-heap по расстоянию, релаксация рёбер.

int[] dijkstra(int n, List<int[]>[] adj, int start) {   // adj[v] = (to, weight)
    int[] dist = new int[n];
    Arrays.fill(dist, Integer.MAX_VALUE);
    dist[start] = 0;
    PriorityQueue<int[]> pq = new PriorityQueue<>((a, b) -> a[1] - b[1]);
    pq.add(new int[]{start, 0});
    while (!pq.isEmpty()) {
        int[] cur = pq.poll();
        int v = cur[0], d = cur[1];
        if (d > dist[v]) continue;                       // устаревшая запись
        for (int[] e : adj[v]) {
            int nd = d + e[1];
            if (nd < dist[e[0]]) { dist[e[0]] = nd; pq.add(new int[]{e[0], nd}); }
        }
    }
    return dist;
}
Dijkstra не работает с отрицательными весами Для отрицательных — Беллман-Форд (редок на собеседованиях). Для единичных весов — обычный BFS (тема 12).

13.4Самопроверка

Что делает топологическая сортировка?

  • Сортирует массив
  • Упорядочивает вершины DAG так, что рёбра идут по порядку
  • Находит кратчайший путь
  • Ищет цикл
Для ориентированного ациклического графа даёт порядок зависимостей.

Как Kahn обнаруживает цикл?

  • Обработано меньше n вершин
  • Очередь пуста
  • Стек переполнен
  • Не обнаруживает
Цикл не имеет вершины со степенью 0 — часть вершин не обработается.

Какую структуру использует Dijkstra?

  • Стек
  • Очередь
  • Min-heap по расстоянию
  • Хэш-таблицу
Куча всегда даёт ближайшую необработанную вершину.

Когда Dijkstra неприменим?

  • При отрицательных весах рёбер
  • В неориентированном графе
  • При единичных весах
  • Всегда применим
Dijkstra требует неотрицательных весов; для отрицательных — Беллман-Форд.
Объясните алгоритм Kahn шаг за шагом.

Считаем входящие степени. Вершины со степенью 0 — стартовые, кладём в очередь. Достаём вершину, добавляем в порядок, уменьшаем степени её соседей; у кого степень стала 0 — в очередь. Повторяем. Если обработали не все — цикл.

Чем Dijkstra отличается от BFS?

BFS — для единичных весов (идёт по уровням). Dijkstra — для произвольных неотрицательных весов, выбирая ближайшую вершину через min-heap.
