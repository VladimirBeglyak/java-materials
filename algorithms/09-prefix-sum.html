Префиксные суммы

Префиксная сумма pre[i] = сумма первых i элементов позволяет за O(1) отвечать на «чему равна сумма подмассива [l, r]?» после O(n) предобработки. В сочетании с хэш-таблицей решает задачи «сколько подмассивов с суммой k». Распознаётся по «сумма подмассива», «сколько отрезков с заданной суммой», «разность сумм».

9.1Построение и сумма подмассива

int[] pre = new int[n + 1];
for (int i = 0; i < n; i++) pre[i + 1] = pre[i] + a[i];

// сумма a[l..r] (включительно) = pre[r+1] - pre[l]
int rangeSum = pre[r + 1] - pre[l];   // O(1)
Индексация pre[n+1] Держим pre[0]=0 — тогда любой отрезок выражается одной формулой без ветвлений, и «пустой» префикс учитывается сам.

9.2Префикс + хэш: сумма k

Сумма подмассива [i, j] равна pre[j+1] − pre[i] = k. Значит, для каждого конца j ищем, сколько раз встречался pre[j+1] − k среди префиксов.

int subarraySum(int[] a, int k) {
    Map<Integer, Integer> cnt = new HashMap<>();
    cnt.put(0, 1);                       // пустой префикс
    int sum = 0, res = 0;
    for (int x : a) {
        sum += x;
        res += cnt.getOrDefault(sum - k, 0);
        cnt.merge(sum, 1, Integer::sum);
    }
    return res;
}

9.3Разностный массив

Для «прибавить значение ко всем элементам отрезка [l, r]» (много раз, потом один раз прочитать) — разностный массив: diff[l] += v, diff[r+1] −= v, затем префиксная сумма diff восстанавливает итог.

int[] diff = new int[n + 1];
for (op : operations) {               // op = (l, r, v)
    diff[l] += v;
    diff[r + 1] -= v;
}
for (int i = 0; i < n; i++) diff[i + 1] += diff[i];   // теперь diff[i] — итоговое значение

9.4Самопроверка

Как за O(1) получить сумму подмассива [l, r]?

  • pre[r+1] - pre[l]
  • Сложить элементы в цикле
  • pre[l] - pre[r]
  • a[r] - a[l]
Разность префиксных сумм даёт сумму любого отрезка.

Как посчитать число подмассивов с суммой k за O(n)?

  • Префикс + хэш-таблица: для каждого конца ищем pre−k среди виденных
  • Двойной цикл
  • Сортировка
  • Двоичный поиск
pre[j] − pre[i] = k ⇔ pre[i] = pre[j] − k; хэш хранит частоты префиксов.

Зачем нужен разностный массив?

  • Сортировать
  • Искать максимум
  • Много раз прибавлять на отрезке, затем один раз прочитать итог
  • Удалять дубликаты
Каждая операция на отрезке за O(1), восстановление — одним проходом.

Почему pre имеет размер n+1 с pre[0]=0?

  • Для скорости
  • Для экономии памяти
  • Чтобы формула отрезка работала единообразно, включая l=0
  • Это ошибка
pre[0]=0 — «пустой» префикс; тогда pre[r+1]-pre[0] корректно даёт сумму с начала.
Что означает условие pre[j] − pre[i] = k геометрически?

Сумма элементов с i по j−1 равна k. Поэтому поиск отрезков с суммой k сводится к подсчёту пар префиксов с разностью k.

Когда префиксные суммы не подходят?

Когда значения меняются (нужны обновления) — тогда нужны дерево Фенвика или дерево отрезков. Префиксные суммы — для статического массива с запросами суммы.
