Интервалы

Задачи про интервалы (встречи, расписания, отрезки) почти всегда решаются сортировкой по началу (или концу) и одним проходом. Распознаётся по «объединить пересекающиеся отрезки», «сколько встреч можно посетить», «минимальное число залов», «вставить интервал».

10.1Объединение интервалов

Сортируем по началу, затем проходим: если следующий начинается до конца текущего — объединяем.

int[][] merge(int[][] intervals) {
    Arrays.sort(intervals, (a, b) -> a[0] - b[0]);
    List<int[]> res = new ArrayList<>();
    for (int[] iv : intervals) {
        if (res.isEmpty() || res.getLast()[1] < iv[0]) {
            res.add(iv);                         // не пересекается
        } else {
            res.getLast()[1] = Math.max(res.getLast()[1], iv[1]);   // расширить
        }
    }
    return res.toArray(new int[0][]);
}

10.2Проверка пересечения

Два интервала [a1,a2] и [b1,b2] пересекаются, если a1 <= b2 && b1 <= a2 (начало одного не позже конца другого).

boolean overlap(int[] a, int[] b) {
    return a[0] <= b[1] && b[0] <= a[1];
}

10.3Минимальное число залов

Классика Meeting Rooms II. Считаем события: начало встречи = +1, конец = −1; максимум накопленной суммы — число одновременно идущих встреч = число залов.

int minRooms(int[][] meetings) {
    int n = meetings.length;
    int[] start = new int[n], end = new int[n];
    for (int i = 0; i < n; i++) { start[i] = meetings[i][0]; end[i] = meetings[i][1]; }
    Arrays.sort(start); Arrays.sort(end);
    int rooms = 0, max = 0, j = 0;
    for (int i = 0; i < n; i++) {
        if (start[i] < end[j]) rooms++;   // началась раньше, чем закончилась предыдущая
        else { j++; }                     // одна закончилась — зал освободился
        max = Math.max(max, rooms);
    }
    return max;
}
Sweep line (заметание) Идея «событий» — начало +1, конец −1, накопленная сумма = текущее число активных интервалов — универсальна для задач о перекрытии.

10.4Самопроверка

С чего начинают почти все задачи про интервалы?

  • С хэш-таблицы
  • С сортировки по началу (или концу)
  • С кучи
  • Со стека
Сортировка даёт порядок, после которого пересечения идут подряд.

Когда два интервала [a1,a2] и [b1,b2] пересекаются?

  • a1 <= b2 && b1 <= a2
  • a2 < b1
  • a1 > b2
  • Только при равенстве
Начало одного не позже конца другого — стандартная проверка пересечения.

Как посчитать минимальное число залов для встреч?

  • Sweep line: начало +1, конец −1, максимум накопленной суммы
  • Сортировкой и двойным циклом
  • Хэш-таблицей
  • Двоичным поиском
Максимум одновременных встреч = нужное число залов.

Как объединить пересекающиеся интервалы?

  • Сортировать по началу и расширять текущий, если следующий пересекается
  • Перемешать
  • Взять минимумы
  • Удалить все
После сортировки пересекающиеся идут подряд — расширяем конец максимумом.
Что такое sweep line (заметающая прямая)?

Метод: превращаем интервалы в события (начало +1, конец −1), сортируем события и идём по ним, поддерживая счётчик активных. Максимум/минимум счётчика отвечает на вопросы о перекрытии.

Как вставить новый интервал в набор непересекающихся?

Добавить интервал в список, отсортировать по началу и выполнить merge. Или за один проход: добавить все, что до нового, затем объединить пересекающиеся с новым, затем добавить остальные.
