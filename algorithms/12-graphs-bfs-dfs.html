Графы: BFS и DFS

Граф — это вершины и рёбра; обходят его двумя способами: DFS (вглубь, рекурсия/стек) и BFS (вширь, очередь). BFS находит кратчайший путь в невзвешенном графе, DFS — компоненты связности, циклы, топологический порядок. Главное отличие от дерева — нужен массив visited, чтобы не зациклиться.

12.1Представление графа

Два способа: матрица смежности (O(V²) памяти) и списки смежности (O(V+E)). Для собеседований почти всегда списки.

List<List<Integer>> adj = new ArrayList<>();
for (int i = 0; i < n; i++) adj.add(new ArrayList<>());
for (int[] e : edges) {               // неориентированный граф
    adj.get(e[0]).add(e[1]);
    adj.get(e[1]).add(e[0]);
}

12.2DFS

void dfs(int v, List<List<Integer>> adj, boolean[] visited) {
    visited[v] = true;
    for (int u : adj.get(v)) {
        if (!visited[u]) dfs(u, adj, visited);
    }
}

12.3BFS

int bfs(int start, int target, List<List<Integer>> adj) {
    boolean[] visited = new boolean[adj.size()];
    Deque<Integer> q = new ArrayDeque<>();
    q.add(start); visited[start] = true;
    int dist = 0;
    while (!q.isEmpty()) {
        int size = q.size();
        for (int i = 0; i < size; i++) {
            int v = q.poll();
            if (v == target) return dist;          // ближайшее = кратчайшее
            for (int u : adj.get(v)) if (!visited[u]) { visited[u] = true; q.add(u); }
        }
        dist++;
    }
    return -1;
}
BFS по уровням = кратчайший путь BFS проходит вершины по возрастанию расстояния, поэтому первая встреча цели — минимальная дистанция (для единичных весов).

12.4Компоненты связности

int numIslands(char[][] grid) {
    int count = 0;
    for (int r = 0; r < grid.length; r++)
        for (int c = 0; c < grid[0].length; c++)
            if (grid[r][c] == '1') { count++; dfs(grid, r, c); }   // затапливаем остров
    return count;
}
void dfs(char[][] g, int r, int c) {
    if (r < 0 || c < 0 || r >= g.length || c >= g[0].length || g[r][c] != '1') return;
    g[r][c] = '0';                       // пометили посещённой (затопили)
    dfs(g, r+1, c); dfs(g, r-1, c); dfs(g, r, c+1); dfs(g, r, c-1);
}

12.5Самопроверка

Зачем в обходе графа нужен visited?

  • Чтобы не зациклиться на циклах графа
  • Для скорости
  • Для сортировки
  • Не нужен
В графе есть циклы; без visited обход зациклится.

Что находит BFS в невзвешенном графе?

  • Кратчайший путь (минимальное число рёбер)
  • Максимальный поток
  • Топологический порядок
  • Циклы
BFS идёт по уровням расстояния — первая встреча цели минимальна.

Какая структура для DFS итеративно и для BFS?

  • Стек для DFS, очередь для BFS
  • Очередь для обоих
  • Стек для обоих
  • Куча для обоих
DFS — LIFO (стек), BFS — FIFO (очередь).

Как посчитать число островов в сетке?

  • Для каждой клетки '1' запустить DFS, «затопив» весь остров, и считать запуски
  • Сложить все единицы
  • Отсортировать
  • Хэш-таблицей
Каждый запуск DFS поглощает целый остров; число запусков = число компонент.
Когда выбирать списки смежности, а когда матрицу?

Списки — O(V+E) памяти, хороши для разреженных графов. Матрица — O(V²), удобна для плотных графов и быстрой проверки ребра, но дорога по памяти.

Чем DFS отличается от BFS по применению?

BFS — кратчайший путь в невзвешенном графе, обход по уровням. DFS — компоненты связности, поиск циклов, топологическая сортировка, backtracking.
