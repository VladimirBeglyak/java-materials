6.1Классический стек: проверка скобок

Стек — стопка: новое кладём наверх, берём тоже сверху. Последнее положенное уходит первым. Так работает кнопка «Отменить» в редакторе: отменяется самое последнее действие, потом предпоследнее.

Классическая задача: правильно ли расставлены скобки в «( [ { } ] )»? Правило простое:

  • Видим открывающую скобку — кладём на стопку.
  • Видим закрывающую — снимаем верхнюю и проверяем, что они пара. Не пара или стопка пуста — ошибка.
  • В конце стопка должна быть пустой — иначе какую-то скобку не закрыли.

Стопка пуста — всё закрыто в правильном порядке. Для «( ] » на втором шаге была бы ошибка.

Стек подходит везде, где важно «последнее открытое закрывается первым»: вложенные скобки, папки в папках, вызовы функций, кнопка «Назад» в браузере.

Главная мысль Стек — «последним пришёл, первым ушёл». Он идеален для всего вложенного.

6.2Монотонный стек: кто увидит кого

Задача: для каждого дня найти, через сколько дней станет теплее. В лоб — для каждого дня смотреть вперёд, пока не найдём день теплее: O(n²).

Хитрость: держать стопку дней, которые ещё ждут своего тёплого дня. Каждый новый день смотрит на верх стопки: «я теплее тебя?». Если да — для того дня ответ найден, снимаем его и проверяем следующий сверху. Потом кладём новый день в стопку — теперь он тоже ждёт.

Представьте ряд людей разного роста, смотрящих вправо. Когда приходит высокий человек, все стоящие перед ним низкие «упираются» в него взглядом — для них ответ найден, и они уходят из очереди ожидающих. В стопке всегда остаются дни, упорядоченные от тёплых внизу к холодным наверху — поэтому стек и называют монотонным.

Каждый день один раз кладётся в стопку и не больше одного раза снимается — получается O(n).

Главная мысль «Ближайший больший (или меньший) элемент» — задача для монотонного стека. Стопка хранит тех, кто ещё ждёт ответа.

Последний положенный — первый снятый.

Проверяем скобки «( ]». Что произойдёт на «]»?

  • положим её на стопку
  • всё в порядке
  • пропустим её
  • снимем «(» — это не пара для «]», значит, ошибка
Закрывающая скобка обязана быть парой к последней открытой.

Все скобки прочитаны, но в стопке осталось «(». Скобки правильные?

  • нет: какую-то скобку не закрыли
  • да
  • зависит от длины
  • да, если она одна
В конце стопка должна быть пустой.

Какая задача — для монотонного стека?

  • сумма всех чисел
  • поиск числа в упорядоченном списке
  • для каждого дня найти ближайший следующий день теплее
  • группировка анаграмм
«Ближайший больший / меньший» — его классическая задача.

Почему монотонный стек работает за O(n)?

  • стопка всегда пустая
  • каждый элемент один раз кладётся и не больше одного раза снимается
  • он работает только на маленьких данных
  • это неправда
Всего не больше 2n операций со стопкой.
