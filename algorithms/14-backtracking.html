Рекурсия и backtracking

Backtracking — это перебор всех решений с возвратом: пробуем вариант, если он ведёт в тупик — откатываемся и пробуем другой. Он решает «найти все подмножества/перестановки/комбинации», «N ферзей», «судоку», «разбить строку». Шаблон всегда один: выбор → рекурсия → отмена выбора.

14.1Рекурсия: база и шаг

Любая рекурсия состоит из базового случая (когда остановиться) и рекурсивного шага (сведение к меньшей задаче). Без базы — переполнение стека.

14.2Шаблон backtracking

void backtrack(State state) {
    if (state.isComplete()) { record(state); return; }   // нашли решение
    for (Choice c : state.choices()) {
        state.apply(c);      // выбор
        backtrack(state);    // рекурсия
        state.undo(c);       // отмена выбора
    }
}

14.3Подмножества

void subsets(int[] a, int i, List<Integer> cur, List<List<Integer>> res) {
    if (i == a.length) { res.add(new ArrayList<>(cur)); return; }
    subsets(a, i + 1, cur, res);          // не брать a[i]
    cur.add(a[i]);                        // взять a[i]
    subsets(a, i + 1, cur, res);
    cur.remove(cur.size() - 1);           // откат
}

14.4Перестановки

void permute(int[] a, int start, List<List<Integer>> res) {
    if (start == a.length) { res.add(toList(a)); return; }
    for (int i = start; i < a.length; i++) {
        swap(a, start, i);      // поставить a[i] на позицию start
        permute(a, start + 1, res);
        swap(a, start, i);      // откат
    }
}

14.5N ферзей (суть)

Ставим ферзей построчно: на каждой строке пробуем каждую колонку, проверяя, не бьют ли уже поставленные. Если дошли до последней строки — решение найдено; иначе откат.

Сложность backtracking Обычно экспоненциальная (подмножества 2ⁿ, перестановки n!). Это нормально — задачи переборные; ключ в отсечениях (pruning), которые отбрасывают целые ветви.

14.6Самопроверка

Из чего состоит рекурсия?

  • Из базового случая и рекурсивного шага
  • Только из цикла
  • Из сортировки
  • Из хэш-таблицы
База — когда остановиться; шаг — сведение к меньшей задаче.

Что делает backtracking после рекурсивного вызова?

  • Отменяет сделанный выбор (undo)
  • Завершает программу
  • Очищает массив
  • Ничего
Откат позволяет попробовать следующий вариант с тем же начальным состоянием.

Какая сложность перебора всех подмножеств?

  • O(2ⁿ)
  • O(n)
  • O(n log n)
  • O(n²)
Каждый элемент берём или нет — 2ⁿ подмножеств.

Что такое pruning в backtracking?

  • Отсечение заведомо невалидных ветвей
  • Сортировка
  • Кэширование
  • Параллелизм
Проверка валидности до рекурсии отбрасывает целые поддеревья перебора.
Чем backtracking отличается от полного перебора?

Тем же перебором, но с откатом и отсечениями: как только ветвь заведомо не ведёт к решению, её отбрасывают целиком, а не перебирают до конца.

Как сгенерировать все комбинации длины k из n?

Тем же backtracking, но с параметром оставшихся k: на каждом шаге либо берём текущий элемент (k−1), либо пропускаем; база — k==0.
