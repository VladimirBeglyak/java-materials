Жадные алгоритмы

Жадный алгоритм на каждом шаге выбирает локально оптимальное действие, надеясь, что оно приведёт к глобальному оптимуму. Он быстрый и простой, но работает не всегда — ключевой навык в том, чтобы понимать, когда жадность корректна, а когда нужен DP или перебор.

16.1Идея

Жадность = сделать лучший выбор прямо сейчас, без оглядки на будущее. Она не отменяет решений. Поэтому применима, когда локальный оптимум совпадает с глобальным (свойство «жадного выбора»).

16.2Activity selection

Максимум непересекающихся встреч: отсортировать по времени окончания и брать каждую, которая начинается не раньше конца предыдущей.

int maxActivities(int[][] a) {   // a = [start, end]
    Arrays.sort(a, (x, y) -> x[1] - y[1]);   // по концу!
    int count = 1, end = a[0][1];
    for (int i = 1; i < a.length; i++)
        if (a[i][0] >= end) { count++; end = a[i][1]; }
    return count;
}
Ключ — сортировка по концу Выбирая встречу с самым ранним концом, мы оставляем максимум места для остальных — это и есть жадный выбор.

16.3Размен монет: где жадность ломается

С монетами 1, 5, 10, 25 жадность (брать крупнейшую) даёт оптимум. Но с монетами 1, 3, 4 и суммой 6 жадность возьмёт 4+1+1 (три монеты), а оптимум — 3+3 (две). Поэтому для произвольных монет нужен DP (тема 15).

Проверяйте жадность Жадность корректна не всегда. Прежде чем её применить, задайте вопрос: «может ли локально плохой выбор привести к лучшему глобально?» Если да — жадность неверна.

16.5Самопроверка

Что делает жадный алгоритм на каждом шаге?

  • Выбирает локально оптимальное действие
  • Перебирает все варианты
  • Отменяет решения
  • Сортирует
Жадность — лучший выбор сейчас, без отката.

Как отсортировать встречи для максимума непересекающихся?

  • По времени окончания
  • По времени начала
  • По длительности
  • Случайно
Ранний конец оставляет больше места — это и есть жадный выбор.

Почему жадный размен монет может быть неверен?

  • Локально крупная монета может привести к неоптимальному набору
  • Монеты не сортируются
  • Он всегда медленный
  • Он не работает с целыми
Пример: монеты 1,3,4 и сумма 6 — жадность даёт 3 монеты, оптимум 2.

Когда вместо жадности нужен DP?

  • Когда локальный выбор не гарантирует глобальный оптимум
  • Всегда
  • Никогда
  • Только для строк
Если локально плохой выбор может дать лучший итог — задача требует DP/перебора.
Объясните, почему сортировка по концу корректна для activity selection.

Встреча с самым ранним концом ничем не хуже любой другой как первая: она заканчивается раньше всех, оставляя максимум места для остальных. Это свойство «жадного выбора».

Как проверить, корректна ли жадность для задачи?

Попробовать найти контрпример: может ли «плохой сейчас» выбор дать лучший итог. Если да — жадность неверна. Также помогает доказательство через обмен (swap argument).
