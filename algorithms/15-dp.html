Динамическое программирование

Динамическое программирование (DP) — это оптимизация рекурсии, где перекрывающиеся подзадачи решаются один раз и запоминаются. Вместо экспоненциального перебора — полиномиальное решение. Ключ — выразить ответ через ответы меньших подзадач (рекуррентное соотношение) и выбрать порядок заполнения.

15.1Когда применять DP

Два признака: задача разбивается на перекрывающиеся подзадачи (одни и те же вычисляются многократно) и обладает оптимальной подструктурой (оптимум строится из оптимумов подзадач). Пример — числа Фибоначчи: fib(n) = fib(n−1) + fib(n−2), подзадачи повторяются.

15.2Memoization (сверху вниз)

Пишем рекурсию и кэшируем результаты.

int fib(int n, int[] memo) {
    if (n <= 1) return n;
    if (memo[n] != 0) return memo[n];          // уже считали
    return memo[n] = fib(n - 1, memo) + fib(n - 2, memo);
}

15.3Tabulation (снизу вверх)

Заполняем таблицу от базы к ответу.

int fib(int n) {
    if (n <= 1) return n;
    int[] dp = new int[n + 1];
    dp[0] = 0; dp[1] = 1;
    for (int i = 2; i <= n; i++) dp[i] = dp[i - 1] + dp[i - 2];
    return dp[n];
}
Memoization vs tabulation Сверху вниз проще придумать (рекурсия + кэш), снизу вверх экономит память и избегает переполнения стека. На собеседовании обычно достаточно любого корректного.

LCSdp[i][j] по двум строкамlongest common subsequence
int coinChange(int[] coins, int amount) {
    int[] dp = new int[amount + 1];
    Arrays.fill(dp, amount + 1);
    dp[0] = 0;
    for (int a = 1; a <= amount; a++)
        for (int c : coins)
            if (c <= a) dp[a] = Math.min(dp[a], dp[a - c] + 1);
    return dp[amount] > amount ? -1 : dp[amount];
}

15.5Самопроверка

Какие два признака говорят о DP?

  • Перекрывающиеся подзадачи и оптимальная подструктура
  • Сортировка и поиск
  • Графы и деревья
  • Строки и хэши
Если подзадачи повторяются и оптимум строится из оптимумов — это DP.

Чем memoization отличается от tabulation?

  • Memoization — рекурсия + кэш (сверху вниз), tabulation — таблица снизу вверх
  • Ничем
  • Memoization быстрее
  • Tabulation не работает
Два направления вычислений одного и того же.

Почему наивная рекурсия Фибоначчи экспоненциальна, а DP — линейна?

  • Потому что DP не считает повторяющиеся подзадачи дважды
  • DP использует больше памяти
  • DP не рекурсивен
  • Никакой разницы
Наивно fib(n-2) считается многократно; кэш/таблица убирают дублирование.

Какова рекуррентность coin change?

  • dp[a] = min(dp[a - c] + 1) по монетам c
  • dp[a] = dp[a-1] + 1
  • dp[a] = a
  • dp[a] = max(coins)
Минимум по всем монетам: взять монету c и решить подзадачу a−c.
Опишите 4 шага решения DP-задачи.

1) Определить состояние (что хранит dp), 2) найти рекуррентность (как состояние зависит от меньших), 3) задать базу, 4) выбрать порядок заполнения (или мемоизацию).

Чем рюкзак 0/1 отличается от неограниченного рюкзака?

0/1 — каждый предмет один раз (идём по весам справа налево или 2D), неограниченный — предметы можно брать многократно (идём по весам слева направо в 1D).
