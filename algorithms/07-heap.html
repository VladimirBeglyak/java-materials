Очередь и куча (top-k)

Очередь (FIFO) — для обработки в порядке поступления и BFS. Куча (PriorityQueue) — для задач «k наибольших/наименьших», «k-й по величине», «медиана», «merge k списков»: она всегда держит под рукой минимальный (или максимальный) элемент за O(log n).

7.1Очередь (FIFO)

В Java — ArrayDeque (двусторонняя очередь) или LinkedList. Классика: BFS (тема 12), обработка задач в порядке поступления, буфер.

Deque<Integer> q = new ArrayDeque<>();
q.addLast(1); q.addLast(2);
int first = q.removeFirst();   // 1 — FIFO

7.2Куча (PriorityQueue)

PriorityQueue в Java — min-heap по умолчанию (минимальный элемент наверху). Для max-heap передают обратный компаратор.

PriorityQueue<Integer> minHeap = new PriorityQueue<>();                       // минимум сверху
PriorityQueue<Integer> maxHeap = new PriorityQueue<>(Comparator.reverseOrder()); // максимум сверху

7.3Top-k элементов

Чтобы найти k наибольших, держим min-heap размера k: если пришёл элемент больше вершины — выталкиваем вершину, кладём новый. Так в куче остаются k наибольших, а память O(k) вместо O(n log n) полной сортировки.

int[] topK(int[] a, int k) {
    PriorityQueue<Integer> heap = new PriorityQueue<>();   // min-heap размера k
    for (int x : a) {
        heap.add(x);
        if (heap.size() > k) heap.poll();                  // вытолкнуть минимум
    }
    return heap.stream().mapToInt(Integer::intValue).toArray();
}
Сложность O(n log k) времени, O(k) памяти — против O(n log n) полной сортировки. Если k мало, выигрыш велик.

7.5Самопроверка

Какая структура у PriorityQueue в Java по умолчанию?

  • max-heap
  • min-heap (минимум сверху)
  • стек
  • очередь
PriorityQueue — min-heap по умолчанию; для max-heap — Comparator.reverseOrder().

Как найти k наибольших элементов за O(n log k)?

  • Min-heap размера k: выталкивать минимум, когда размер превышает k
  • Полная сортировка
  • Max-heap размера n
  • Перебор
Min-heap держит k наибольших; минимум выталкивается, когда приходит больший.

Какая сложность merge k отсортированных списков через кучу?

  • O(N log k), N — суммарное число элементов
  • O(N k)
  • O(N log N)
  • O(k²)
Каждый из N элементов проходит через кучу размера k за O(log k).

Где используется очередь (FIFO), а не стек?

  • Скобки
  • Отмена действий
  • Вычисление выражений
  • BFS и обработка в порядке поступления
BFS и очереди задач требуют «первый пришёл — первый обработан».
Почему для top-k используют min-heap, а не max-heap?

Min-heap хранит вершину = наименьший из k. Новый элемент сравнивается с минимумом: если больше — минимум вытесняется. Так куча всегда держит ровно k наибольших, а не все элементы.

Как найти медиану потока чисел?

Двумя кучами: max-heap для меньшей половины и min-heap для большей, поддерживая баланс размеров. Медиана — вершины куч (или их среднее).
