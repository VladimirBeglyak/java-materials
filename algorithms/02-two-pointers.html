Два указателя

Паттерн «два указателя» заменяет вложенный цикл O(n²) одним проходом O(n): два индекса движутся по массиву, сокращая перебор. Распознаётся по фразам «отсортированный массив», «пара с суммой», «палиндром», «удалить дубликаты» — и по трём вариантам: с концов, fast/slow и по двум массивам.

2.1Идея

Вместо того чтобы для каждого элемента перебирать остальные, вы двигаете указатели по правилу, которое за один проход находит ответ. Ключ — упорядоченность: если сумма/значение меньше нужного, двигаем один указатель, если больше — другой.

Как распознать Отсортированный массив + поиск пары/суммы/палиндрома; необходимость сжать массив на месте; сравнение двух последовательностей. Если массив не отсортирован — часто его сначала сортируют O(n log n).

2.2Два указателя с концов

Один указатель слева, другой справа; на каждом шаге сужаем диапазон.

// найти два числа с суммой target (массив отсортирован)
int[] twoSum(int[] a, int target) {
    int l = 0, r = a.length - 1;
    while (l < r) {
        int sum = a[l] + a[r];
        if (sum == target) return new int[]{l, r};
        if (sum < target) l++;       // сумма мала — сдвинуть левый вправо
        else r--;                    // сумма велика — сдвинуть правый влево
    }
    return new int[]{-1, -1};
}
boolean isPalindrome(String s) {
    int l = 0, r = s.length() - 1;
    while (l < r) {
        if (s.charAt(l) != s.charAt(r)) return false;
        l++; r--;
    }
    return true;
}

2.3Fast / slow указатели

Два указателя движутся с разной скоростью. Классика — связанные списки (тема 08): поиск цикла и середины. В массиве — например, удаление дубликатов на месте.

int removeDuplicates(int[] a) {
    int slow = 0;                       // позиция последнего уникального
    for (int fast = 1; fast < a.length; fast++) {
        if (a[fast] != a[slow]) {
            a[++slow] = a[fast];        // новый уникальный элемент
        }
    }
    return slow + 1;                    // длина без дубликатов
}

2.4Два указателя по двум массивам

Слияние двух отсортированных массивов или поиск пересечения.

int[] merge(int[] a, int[] b) {
    int[] r = new int[a.length + b.length];
    int i = 0, j = 0, k = 0;
    while (i < a.length && j < b.length)
        r[k++] = a[i] <= b[j] ? a[i++] : b[j++];
    while (i < a.length) r[k++] = a[i++];
    while (j < b.length) r[k++] = b[j++];
    return r;
}

2.5Самопроверка

Какую сложность даёт два указателя вместо вложенного цикла?

  • O(n²)
  • O(n)
  • O(log n)
  • O(2ⁿ)
Оба указателя проходят массив один раз суммарно — O(n).

В отсортированном массиве сумма a[l]+a[r] меньше target. Что делать?

  • Сдвинуть l вправо
  • Сдвинуть r влево
  • Остановиться
  • Обнулить массив
Сумма мала — нужен больший элемент, левый указатель движется вправо.

Для чего используют fast/slow указатели?

  • Только для сортировки
  • Только для палиндрома
  • Поиск цикла и середины (в связных списках), сжатие массива
  • Только для слияния
Разная скорость движения ловит циклы, середину и позволяет сжимать на месте.

Что часто делают с неотсортированным массивом перед двумя указателями?

  • Ничего
  • Копируют
  • Переворачивают
  • Сортируют (O(n log n))
Паттерн опирается на порядок; сортировка — частая подготовка.
Назовите три варианта паттерна «два указателя».

С концов (left/right, сужение диапазона), fast/slow (разная скорость), по двум массивам (слияние/пересечение).

Как распознать, что задача решается двумя указателями?

Отсортированный массив и поиск пары/суммы, палиндром, удаление дубликатов на месте, сравнение/слияние двух последовательностей. Признак — можно заменить вложенный цикл одним проходом.
