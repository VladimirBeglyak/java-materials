Дата и время

Работа с датами — одна из самых коварных частей SQL из-за часовых поясов и различий диалектов. Ядро — понимать разницу между timestamp (момент без привязки к зоне) и timestamptz (момент в абсолютном времени), уметь извлекать части даты и считать интервалы.

13.1Типы дат

Тип (PostgreSQL)Что хранитПример
dateкалендарная дата2026-01-10
timeвремя суток14:30:00
timestampдата + время без зоны2026-01-10 14:30
timestamptzмомент в абсолютном времени (UTC внутри)2026-01-10 14:30+03
intervalпромежуток времениinterval '1 day'
timestamp против timestamptz timestamptz хранит конкретный момент и корректно пересчитывается между зонами; timestamp — «настенные часы» без зоны, поэтому при смене часового пояса данные искажаются. Для событий (создание заказа, логи) используйте timestamptz.

13.2Интервалы и арифметика

-- прибавить/вычесть интервал
SELECT now() + interval '1 day';
SELECT now() - interval '3 hours';
SELECT date '2026-01-10' + interval '1 month';

-- разница между датами — интервал
SELECT date '2026-06-15' - date '2026-01-10';   -- 156 days

-- возраст
SELECT age(date '2026-01-10');                    -- сколько прошло до now()

13.3EXTRACT и date_part

EXTRACT(часть FROM дата) достаёт компонент даты: год, месяц, день, час, день недели и т.д. Это базовый инструмент группировки по периодам.

SELECT EXTRACT(year FROM created_at)   AS yr,
       EXTRACT(month FROM created_at)  AS mon,
       EXTRACT(dow FROM created_at)    AS dow   -- день недели (0=вс)
FROM orders;
ЧастьСмысл
year, month, dayкомпоненты даты
hour, minute, secondкомпоненты времени
dowдень недели (0=воскресенье в PostgreSQL)
isodowдень недели (1=понедельник)
epochсекунды с 1970-01-01
week, quarterнеделя/квартал года

13.4date_trunc

date_trunc «обрезает» дату до нужной точности — идеально для группировки по месяцу, часу и т.п.

SELECT date_trunc('month', created_at) AS mon, COUNT(*) AS cnt
FROM orders
GROUP BY date_trunc('month', created_at)
ORDER BY mon;

SELECT date_trunc('day', created_at) FROM orders;   -- 2026-06-01 00:00:00

13.5Часовые пояса

-- текущее время с зоной
SELECT now();                        -- timestamptz
SELECT CURRENT_TIMESTAMP;            -- то же, в стандарте SQL

-- перевести момент в другую зону
SELECT now() AT TIME ZONE 'UTC';
SELECT now() AT TIME ZONE 'Europe/Minsk';
Правило часовых поясов Храните моменты в timestamptz (внутри UTC), а зону применяйте только при отображении пользователю. Так данные остаются корректными при смене зоны сервера или клиента.

13.6Песочница

SQL-песочница: даты (SQLite)

Песочница работает на SQLite: вместо EXTRACT/date_trunc здесь strftime(), а даты хранятся как текст. На PostgreSQL примеры выше из блоков кода (EXTRACT, date_trunc, interval) выполняются напрямую.

13.7Самопроверка

Чем timestamp отличается от timestamptz?

  • Ничем
  • timestamp — «настенные часы» без зоны, timestamptz — момент в абсолютном времени
  • timestamptz быстрее
  • timestamptz не поддерживает даты
timestamptz хранит конкретный момент (внутри UTC) и корректно пересчитывается между зонами; timestamp — без привязки к зоне.

Что делает date_trunc('month', date)?

  • Округляет дату до начала месяца
  • Прибавляет месяц
  • Извлекает номер месяца
  • Удаляет месяц из даты
date_trunc «обрезает» дату до указанной точности: день и время обнуляются, остаётся первый день месяца.

Что вернёт EXTRACT(epoch FROM timestamp)?

  • Год
  • День недели
  • Число секунд с 1970-01-01
  • Миллисекунды
epoch — секунды Unix-времени, удобно для сравнения и арифметики.

Как правильно хранить моменты событий в базе?

  • В строке TEXT
  • В timestamp без зоны
  • В integer
  • В timestamptz (UTC внутри), зону применять при отображении
timestamptz гарантирует корректность при смене зон; зону форматируют только для пользователя.
Как сгруппировать строки по месяцам?

Через GROUP BY date_trunc('month', created_at) (PostgreSQL) или GROUP BY strftime('%Y-%m', created_at) (SQLite). Так все даты месяца схлопываются в одну группу.

Что делает выражение now() AT TIME ZONE 'UTC'?

Переводит текущий момент в указанный часовой пояс. AT TIME ZONE меняет представление момента, не сам момент.
