UNION, INTERSECT, EXCEPT

Эти операторы работают не со строками, а с целыми наборами результатов: объединяют их, находят пересечение или разность. В отличие от JOIN, который «склеивает столбцы», они «склеивают строки» двух запросов с одинаковой структурой столбцов.

8.1UNION

UNION объединяет результаты двух запросов и убирает дубликаты. Порядок строк не гарантирован — добавляйте ORDER BY в конце.

-- все «адреса»: города клиентов и названия категорий в одном столбце
SELECT city AS label FROM customers WHERE city IS NOT NULL
UNION
SELECT name AS label FROM categories
ORDER BY label;
Правила совместимости У обоих запросов должно быть одинаковое число столбцов, и типы соответствующих столбцов должны быть совместимы. Имена столбцов берутся из первого запроса.

8.2UNION ALL

UNION ALL — то же объединение, но без удаления дубликатов. Он быстрее (не нужно сортировать и искать дубликаты) и используется, когда повторы допустимы или заведомо невозможны.

-- объединить два источника строк без проверки дубликатов
SELECT id, name FROM products WHERE price < 1000
UNION ALL
SELECT id, name FROM products WHERE category = 'электроника';   -- повторы возможны

8.3INTERSECT

Возвращает строки, которые есть в обоих результатах.

-- клиенты, которые и заказывали, и живут в Минске
SELECT customer_id FROM orders
INTERSECT
SELECT id FROM customers WHERE city = 'Минск';

8.4EXCEPT

Возвращает строки первого запроса, которых нет во втором.

-- товары, которые ни разу не заказывали
SELECT id FROM products
EXCEPT
SELECT product_id FROM order_items;
Диалекты В MySQL вместо INTERSECT/EXCEPT исторически использовались JOIN-обходы; современный MySQL 8.0.31+ поддерживает INTERSECT/EXCEPT. В Oracle EXCEPT называется MINUS.

8.6Самопроверка

Чем UNION отличается от UNION ALL?

  • UNION работает только с одной таблицей
  • UNION убирает дубликаты, UNION ALL — нет
  • UNION ALL сортирует результат
  • Ничем
UNION удаляет дубликаты строк (и медленнее); UNION ALL сохраняет все строки.

Что вернёт EXCEPT?

  • Строки первого запроса, которых нет во втором
  • Строки, общие для обоих
  • Объединение обоих
  • Разность строк второй минус первой
EXCEPT — разность множеств: из первого результата вычитается второй.

Какое требование у UNION к двум запросам?

  • Одинаковые имена таблиц
  • Одинаковый ORDER BY
  • Одинаковое число столбцов и совместимые типы
  • Одинаковый WHERE
Результаты «склеиваются» по столбцам, поэтому структура должна совпадать. Имена столбцов берутся из первого запроса.

Как в Oracle называется оператор EXCEPT?

  • DIFF
  • SUBTRACT
  • REMOVE
  • MINUS
В Oracle — MINUS, в стандарте SQL и PostgreSQL — EXCEPT.
UNION против JOIN — в чём разница?

JOIN добавляет столбцы, соединяя строки по условию. UNION добавляет строки, объединяя результаты двух запросов с одинаковой структурой. Это «в ширину» против «в длину».

Когда предпочесть UNION ALL обычному UNION?

Когда повторы допустимы по смыслу или заведомо невозможны (непересекающиеся источники). UNION ALL дешевле, потому что не выполняет сортировку/хеширование для удаления дубликатов.
