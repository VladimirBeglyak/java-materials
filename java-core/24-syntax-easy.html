24.1Из чего состоит текст программы

Компилятор разбивает текст на «слова»: ключевые слова (class, if, return), имена (переменных, методов, классов), литералы — значения, записанные прямо в коде (42, 3.14, 'a', "текст", true), операторы и знаки препинания. Удобная мелочь: длинные числа можно разделять подчёркиванием — 1_000_000.

Главная мысль Код — это ключевые слова, имена, литералы и операторы.

24.2Операторы и порядок вычисления

Как в школьной математике, умножение выполняется раньше сложения. Но есть особенности: && и || — «ленивые»: если ответ уже ясен по левой части, правая не вычисляется. Это позволяет писать x != null && x.isEmpty() — до вызова метода у null дело не дойдёт. i++ отдаёт старое значение и потом увеличивает, ++i — наоборот. Когда сомневаетесь в порядке — ставьте скобки.

Главная мысль && и || не вычисляют лишнее. Сомневаетесь в приоритете — скобки.

24.3Биты и сдвиги

Целое число — ряд выключателей. Побитовые операторы &, |, ^, ~ работают с каждым выключателем отдельно, сдвиги << и >> двигают весь ряд (умножение и деление на 2). В прикладном коде они нужны редко: флаги, хэши, работа с байтами. Подробно — в курсе алгоритмов, глава 17.

Главная мысль Побитовые операции — для флагов и байтов; в обычной логике используйте && и ||.

24.4Ветвления и циклы

  • if / else — «если так, сделай это, иначе другое».
  • switch — выбор из многих вариантов по значению.
  • for — цикл со счётчиком; for-each — «для каждого элемента коллекции».
  • while — «повторяй, пока условие верно»; do-while — то же, но хотя бы один раз.
  • break — выйти из цикла, continue — перейти к следующему шагу.
Главная мысль Ветвления выбирают путь, циклы повторяют. for-each — самый частый и безопасный цикл.

24.5Массивы: ряд пронумерованных ячеек

Массив — ряд ячеек одного типа фиксированной длины, нумерация с нуля. Длину нельзя изменить после создания (для этого есть ArrayList, глава 08). Обращение за пределы — исключение ArrayIndexOutOfBoundsException, а не тихая порча памяти. Массив — объект, поэтому переменная хранит адрес (глава 02), а сравнивать содержимое нужно через Arrays.equals.

Главная мысль Массив: фиксированная длина, индексы с нуля, выход за границу — исключение.

В полной главе: 24.5 Массивы

24.6Методы и перегрузка

Метод — именованный кусок работы: принимает параметры, может вернуть результат. Методов с одним именем может быть несколько, если у них разные параметры (перегрузка), — компилятор выбирает подходящий по типам аргументов. varargs (int... nums) позволяет передать любое число аргументов.

Главная мысль Перегрузка — одно имя, разные параметры; выбирает компилятор.

В полной главе: 24.6 Методы: сигнатура, varargs, выбор перегрузки

24.7Где «живёт» переменная

Переменная видна внутри фигурных скобок, где объявлена. Локальную переменную нужно присвоить до использования, а поля класса получают значения по умолчанию (0, false, null). Если локальная переменная называется так же, как поле, она его «затеняет» — чтобы обратиться к полю, пишут this.name.

Главная мысль Область видимости — блок в фигурных скобках. Локальные — без значений по умолчанию.

В полной главе: 24.7 Переменные: виды, области видимости, затенение

24.8Пакеты и точка входа

Пакеты — папки для классов, они же защищают от совпадения имён: com.shop.Order и com.bank.Order — разные классы. import позволяет писать короткое имя. Программа начинается с метода public static void main(String[] args); в новых версиях Java для простых программ можно писать короче.

Главная мысль Пакет = папка + полное имя класса. Вход в программу — main.

24.10Проверьте себя

Почему s != null && s.isEmpty() не падает при s = null?

  • isEmpty умеет работать с null
  • && не вычисляет правую часть, если левая уже false
  • Java игнорирует ошибки
  • падает
Короткое замыкание.

Массив из 5 элементов. Какой последний допустимый индекс?

  • 4
  • 5
  • 6
  • любой
Нумерация с нуля: 0…4.

Что произойдёт при обращении к arr[10] у массива длины 5?

  • вернётся 0
  • вернётся null
  • прочитается соседняя память
  • исключение ArrayIndexOutOfBoundsException
Java проверяет границы.

Что такое перегрузка методов?

  • метод, который слишком много делает
  • замена метода родителя в наследнике
  • несколько методов с одним именем, но разными параметрами
  • вызов метода в цикле
Подходящий вариант выбирает компилятор по типам аргументов.

Чему равно поле int класса, если ему ничего не присвоили?

  • случайному числу
  • 0
  • null
  • будет ошибка компиляции
Поля получают значения по умолчанию, локальные переменные — нет.
