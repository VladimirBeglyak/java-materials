Java Core: язык и платформа

Цель — понимать, что происходит за каждой строкой: как устроены типы и строки, почему equals и hashCode связаны, что делает HashMap при коллизии, куда исчезают generics после компиляции и как JVM управляет памятью.

Русский языкКод + схемы + вопросыСимуляторы и тесты в каждой темеПрогресс сохраняется в браузере

Как устроена тема целиком

Курс идёт от того, что вы пишете, к тому, что с этим делает JVM. Каждый следующий слой объясняет «магию» предыдущего: коллекции стоят на контрактах equals и hashCode, стримы — на лямбдах, а Spring — на рефлексии и загрузке классов.

Как работать с пособием

  1. Каждый пример запустите сами. В каждой главе перед самопроверкой есть практикум: программы для набора в IDE, прогноз результата и реальный вывод JDK 25 для сверки. Короткие фрагменты удобно проверять в jshell.
  2. Меняйте по одной детали и предсказывайте результат: уберите hashCode, замените 127 на 128, переставьте блоки инициализации.
  3. Смотрите в байткод, когда хочется понять «а что на самом деле»: javap -c -p Класс отвечает на большинство вопросов о компиляторе.
  4. Отвечайте на вопросы самопроверки вслух, затем раскрывайте ответ.
  5. После темы 15 пройдите задачи темы 16 — они покажут, какие главы стоит перечитать.
Версии Java Основа — Java 17 и 21 (LTS). Возможности более новых версий помечены номером; в теме 12 собрана общая хронология. Там, где поведение менялось (кодировка по умолчанию, устройство строк, сборщики мусора), указаны обе стороны — на собеседованиях спрашивают и «как было», и «как стало».
О точности Ответы всех 17 задач темы 16 и основные примеры вида «что выведет код» из остальных глав проверены запуском на JDK 25. Остальной текст написан по памяти, без сверки каждого утверждения с документацией: значения по умолчанию, пороги и статус возможностей в конкретной версии JDK (особенно 22–25) перед использованием в рабочем коде проверяйте по Javadoc и описаниям JEP.

Практикум: подготовка рабочего места

В каждой главе перед самопроверкой есть раздел «Практикум: пишем и запускаем» — более сотни лабораторных, где вы набираете код, запускаете его и смотрите, как ведёт себя язык и стандартная библиотека — от передачи параметров и пула строк до HashMap, стримов, JDBC и тестов. Ожидаемый вывод под каждой командой снят настоящим запуском на OpenJDK 25.0.2 (Windows x64, 18 логических процессоров, 32 ГБ): числа, адреса и времена у вас будут свои, а поведение — тем же.

1. JDK и IDE

  1. JDK 25 (LTS): в IntelliJ IDEA — File → Project Structure → SDK → Add SDK → Download JDK → версия 25 (Oracle OpenJDK, Temurin или Corretto). Проверка в терминале: java -version и javac -version должны показать 25.
  2. Проект java-core-lab (File → New → Project → Java, без системы сборки). Для каждой главы — свой модуль: File → New → Module → ch01, ch02… Классы кладите прямо в src (пакет по умолчанию): имена классов внутри главы не повторяются, а команды из пособия работают без пакетов.
  3. Language level модуля — 25 (Project Structure → Modules → Language level), иначе новые возможности языка не скомпилируются.

2. Где в IDEA то, что в пособии написано командой

Команды в пособии написаны так, будто вы стоите в каталоге с исходником: проще всего в терминале перейти в src модуля (cd ch01/src) и запускать javac Hello.java / java Hello там же — или однофайловым режимом java Hello.java без отдельной компиляции.

4. Как проходить лабораторную

  1. Наберите код руками (кнопки copy можно скрыть переключателем «набираю руками» в начале практикума).
  2. На шагах со знаком ? сначала запишите прогноз в поле — он сохраняется в браузере, — затем запустите и нажмите «Сверить».
  3. Сравните свой вывод с образцом под спойлером «Вывод». Если отличается не только числами — это повод разобраться, а не пропустить.
  4. Блок «Поэкспериментируйте» — главное: меняйте по одной детали и предсказывайте результат. Ответы спрятаны под стрелками.
  5. Отмечайте шаги галочкой «сделал» — прогресс лабораторной виден в её заголовке.
