Java Core: язык и платформа

Цель — понимать, что происходит за каждой строкой: как устроены типы и строки, почему equals и hashCode связаны, что делает HashMap при коллизии, куда исчезают generics после компиляции и как JVM управляет памятью.

Русский языкКод + схемы + вопросыСимуляторы и тесты в каждой темеПрогресс сохраняется в браузере

Как устроена тема целиком

Курс идёт от того, что вы пишете, к тому, что с этим делает JVM. Каждый следующий слой объясняет «магию» предыдущего: коллекции стоят на контрактах equals и hashCode, стримы — на лямбдах, а Spring — на рефлексии и загрузке классов.

Как работать с пособием

  1. Каждый пример запустите сами. Проще всего — в jshell: вставить фрагмент и увидеть результат. Перед запуском запишите, что ожидаете.
  2. Меняйте по одной детали и предсказывайте результат: уберите hashCode, замените 127 на 128, переставьте блоки инициализации.
  3. Смотрите в байткод, когда хочется понять «а что на самом деле»: javap -c -p Класс отвечает на большинство вопросов о компиляторе.
  4. Отвечайте на вопросы самопроверки вслух, затем раскрывайте ответ.
  5. После темы 15 пройдите задачи темы 16 — они покажут, какие главы стоит перечитать.
Версии Java Основа — Java 17 и 21 (LTS). Возможности более новых версий помечены номером; в теме 12 собрана общая хронология. Там, где поведение менялось (кодировка по умолчанию, устройство строк, сборщики мусора), указаны обе стороны — на собеседованиях спрашивают и «как было», и «как стало».
О точности Ответы всех 17 задач темы 16 и основные примеры вида «что выведет код» из остальных глав проверены запуском на JDK 25. Остальной текст написан по памяти, без сверки каждого утверждения с документацией: значения по умолчанию, пороги и статус возможностей в конкретной версии JDK (особенно 22–25) перед использованием в рабочем коде проверяйте по Javadoc и описаниям JEP.
