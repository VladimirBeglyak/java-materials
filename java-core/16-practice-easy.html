16.1Как отвечать на вопрос по Java Core

  1. Одной фразой — что это. «HashMap — словарь, который ищет значения по ключу почти мгновенно».
  2. Как устроено. «Массив ящиков, ящик выбирается по hashCode, внутри — сравнение через equals».
  3. Где ловушка. «Если переопределить equals без hashCode — равные ключи потеряются».
  4. Пример из практики, если есть.
Главная мысль Что это → как устроено → где ловушка → пример.

16.3Что проверять в чужом коде

  • Строки и обёртки сравниваются через equals.
  • equals и hashCode переопределены вместе (или используется record).
  • Ресурсы закрываются через try-with-resources.
  • Нет пустых catch и проглоченных исключений.
  • Деньги не в double.
  • Коллекции наружу отдаются неизменяемыми, ключи map не меняются.
  • Нет склейки строк в цикле через +.
Главная мысль Семь пунктов ловят большинство типичных ошибок Java Core.

16.4Чего ждут на разных уровнях

Junior

Типы, строки, ООП, исключения, основные коллекции. Уметь объяснить и не попасться на == .

Middle

Устройство HashMap, generics и PECS, стримы, лямбды, современная Java, основы памяти.

Senior

GC и диагностика, загрузка классов, JIT, прокси, компромиссы в дизайне и опыт разбора проблем.

Главная мысль Чем выше уровень, тем больше вопросов «почему так устроено» и «как вы это чинили».

16.7Проверьте себя

С чего лучше начать ответ «как работает HashMap»?

  • с исходного кода
  • одной фразой: что это и зачем
  • с истории Java
  • с вопроса интервьюеру
Дальше — устройство, ловушки, пример.

Что выведет метод, где в try стоит return 1, а в finally — печать «X»?

  • только 1, без X
  • ошибку компиляции
  • ничего
  • напечатает X, затем вернёт 1
finally выполняется всегда, даже при return.

Какую ошибку вы бы отметили на ревью: if (status == "PAID")?

  • сравнение строк через == вместо equals
  • нет ошибки
  • нужны одинарные кавычки
  • нужен switch
== сравнивает адреса.

В классе переопределён equals, но нет hashCode. Что сказать на ревью?

  • всё хорошо
  • нужно удалить equals
  • переопределить hashCode по тем же полям или сделать record
  • заменить на toString
Иначе сломаются HashMap и HashSet.
