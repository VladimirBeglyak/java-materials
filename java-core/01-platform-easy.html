1.1JDK, JRE, JVM: мастерская, кухня и повар

JVM — повар

Виртуальная машина Java. Она читает программу и исполняет её на конкретном компьютере. Своя JVM есть для каждой системы.

JRE — кухня

JVM плюс стандартная библиотека: всё, что нужно, чтобы запускать программы. Отдельно её сейчас почти не распространяют.

JDK — мастерская

JRE плюс инструменты разработчика: компилятор javac, отладчик, профилировщики. Нужна, чтобы писать программы.

Главная мысль JVM исполняет, JRE = JVM + библиотека, JDK = JRE + инструменты. Разработчику нужен JDK.

1.2От текста до процессора

Путь программы Hello
Hello.java — текст, который написал человекjavac Hello.java → Hello.class — байткод
(не команды процессора, а универсальные команды для JVM)java Hello → JVM загружает класс и начинает исполнять байткод
сначала интерпретатором, «переводя на ходу»часто выполняемый код JIT-компилятор переводит
в настоящие команды процессора → программа ускоряется

Текст на языке Java.

javac переводит в байткод — язык, общий для всех JVM.

JVM на этом компьютере начинает исполнять байткод.

«Горячие» места компилируются в машинный код прямо во время работы.

Отсюда знаменитое «написано один раз — работает везде»: байткод один, а JVM своя для каждой системы.

Главная мысль Исходник → байткод (javac) → исполнение в JVM, а горячий код JIT превращает в машинный.

1.3Байткод: язык для виртуального повара

Байткод — простые команды вроде «положи число на стопку», «сложи два верхних», «вызови метод». JVM работает как калькулятор со стопкой: числа кладутся на стопку, операция снимает верхние и кладёт результат. Посмотреть байткод своего класса можно командой javap -c.

Главная мысль Байткод — простые команды для стековой машины JVM, одинаковые на любом компьютере.

В полной главе: 1.3 Байткод

1.4Запуск: что происходит при java Hello

JVM запускается, готовит память, загружает нужные классы (ваш и стандартные), проверяет, что байткод корректен и не нарушает правил безопасности, и вызывает метод main. С Java 11 маленькую программу из одного файла можно запустить сразу командой java Hello.java — компиляция пройдёт незаметно в памяти.

Главная мысль Запуск = старт JVM → загрузка и проверка классов → вызов main.

В полной главе: 1.4 Запуск программы

1.5Версии и LTS

Новая версия Java выходит каждые полгода. Но компании обычно используют версии с долгой поддержкой (LTS) — их обновляют исправлениями годами: 17, 21, 25. Промежуточные версии живут полгода и нужны, чтобы попробовать новинки. Сам JDK выпускают разные поставщики (Oracle, Eclipse Temurin, Amazon Corretto и другие) — внутри это почти один и тот же OpenJDK.

Главная мысль Для работы выбирают LTS-версию. Поставщиков много, основа одна — OpenJDK.

1.6Инструменты JDK

  • javac — компилятор, java — запуск программы.
  • jar — упаковать классы в один архив.
  • javap — показать байткод.
  • jshell — «песочница»: пишешь строчку Java и сразу видишь результат.
  • jcmd, jstack, JFR — заглянуть внутрь работающей программы: потоки, память, нагрузка.
Главная мысль JDK — это не только компилятор, но и набор инструментов для упаковки, экспериментов и диагностики.

1.8Проверьте себя

Что нужно установить, чтобы писать и компилировать Java-программы?

  • только JVM
  • только JRE
  • JDK
  • браузер
Компилятор javac входит только в JDK.

Во что javac переводит исходник?

  • в байткод для JVM
  • в команды процессора
  • в текст на C
  • в картинку
Байткод универсален, команды процессора делает уже JVM (JIT).

Почему Java-программа работает на разных системах без перекомпиляции?

  • Java есть только для Linux
  • байткод один, а JVM своя для каждой системы
  • программа содержит версии для всех систем
  • это не так
«Написано один раз — работает везде».

Какую версию Java обычно выбирают для рабочих проектов?

  • самую новую промежуточную
  • самую старую
  • любую
  • LTS-версию с долгой поддержкой
LTS годами получает исправления.

Что делает JIT-компилятор?

  • проверяет орфографию
  • собирает JAR
  • переводит часто выполняемый байткод в машинный код во время работы
  • удаляет неиспользуемые классы
Поэтому Java-программы «разогреваются».
