Class-файл — простыми словами

Что на самом деле лежит в .class-файле? Разберёмся, как он устроен, что такое пул констант, как записываются типы (дескрипторы) и что такое атрибуты. Это помогает понимать ошибки вроде UnsupportedClassVersionError и работу инструментов, которые правят байткод.

2.1Общая структура

  1. Магическое число CAFEBABE — «это class-файл».
  2. Версия — для какой Java собран (Java 21 — версия 65). Старая JVM не запустит новый файл: UnsupportedClassVersionError.
  3. Пул констант — справочник всех имён, строк и ссылок.
  4. Флаги и имена — класс, его родитель, интерфейсы.
  5. Поля и методы, у методов — байткод.
  6. Атрибуты — дополнительные сведения.
Главная мысль CAFEBABE, версия, справочник констант, поля, методы, атрибуты.

2.2Как заглянуть внутрь

Команда javap -v MyClass показывает всё содержимое файла в читаемом виде: версию, пул констант, байткод методов. Это лучший способ увидеть, во что компилятор превратил ваш код.

Главная мысль javap -v — рентген class-файла.

В полной главе: 2.2 Разбор настоящего файла

2.3Пул констант: справочник

Вместо того чтобы много раз писать «java/lang/String» или «Привет», class-файл хранит каждую такую вещь один раз в пуле констант под номером, а везде ссылается номером: «вызвать метод из записи №12». Как сноски в книге. Записи бывают разные: строки, числа, имена классов, ссылки на методы и поля.

Главная мысль Пул констант — справочник с номерами; всё остальное ссылается на него.

В полной главе: 2.3 Пул констант

2.4Дескрипторы: типы короткими буквами

Типы в class-файле записываются сокращённо: I — int, J — long, Z — boolean, Ljava/lang/String; — объект String, [I — массив int. Метод int sum(int, int) записывается как (II)I. Эти записи встречаются в сообщениях об ошибках — например, в NoSuchMethodError.

Главная мысль (II)I — «принимает два int, возвращает int». Так JVM записывает сигнатуры.

В полной главе: 2.4 Дескрипторы

2.5Атрибуты

Атрибуты — дополнительные «наклейки»: Code — сам байткод метода, LineNumberTable — соответствие строк исходника (для стек-трейсов), LocalVariableTable — имена переменных (для отладчика), аннотации, информация о generics. Без отладочных атрибутов программа работает, но стек-трейсы без номеров строк.

Главная мысль Атрибуты хранят байткод, номера строк, аннотации и прочее.

2.7Проверьте себя

Что означает UnsupportedClassVersionError?

  • класс повреждён
  • класс собран для более новой Java, чем та, что его запускает
  • нет метода main
  • нет прав
Версия class-файла выше поддерживаемой.

Зачем нужен пул констант?

  • для скорости процессора
  • для шифрования
  • для хранения объектов
  • чтобы хранить имена и значения один раз и ссылаться на них по номеру
Как сноски в книге.

Что означает дескриптор (Ljava/lang/String;)V?

  • метод принимает String и ничего не возвращает
  • метод возвращает String
  • поле типа String
  • массив строк
V — void.

Какой инструмент покажет байткод класса?

  • javac
  • jar
  • javap -c (или -v)
  • jshell
javap дизассемблирует class-файл.

Почему без LineNumberTable стек-трейсы хуже?

  • они длиннее
  • в них не будет номеров строк исходника
  • их нельзя напечатать
  • не хуже
Атрибут сопоставляет байткод и строки.
