Коллекции Java изнутри и итераторы

Подробное пособие по Collections Framework: контракты интерфейсов, итераторы и fail-fast, устройство каждой основной реализации — от массива ArrayList и кольцевого буфера ArrayDeque до хеш-таблицы HashMap, красно-чёрного дерева TreeMap и двоичной кучи PriorityQueue, — неизменяемые коллекции и представления, Spliterator и стримы, конкурентные коллекции, производительность и типичные ошибки. Каждая структура разобрана в живом симуляторе, где видно, что происходит внутри при каждой операции.

Как работать с пособием

  1. Прощёлкивайте симуляторы до конца и предсказывайте результат каждого шага — так структура данных запоминается не как текст, а как модель.
  2. Читайте исходники JDK: в IDE откройте ArrayList, HashMap, TreeMap, PriorityQueue, ArrayDeque — после курса они читаются легко, а комментарии в них (например, о распределении Пуассона в HashMap) — отдельное удовольствие.
  3. Пишите свои реализации: итератор, LRU-кэш, кучу, хеш-таблицу с открытой адресацией — задачи темы 21.
  4. Мерьте JMH, а не на глаз: тема 19.
  5. Отмечайте темы изученными — прогресс виден в меню слева.
Версии и соседние пособия Основа — Java 21 (LTS) с отметками о Java 9–25 (List.of, newHashMap, Stream.toList, Sequenced Collections, Gatherers). Обзор коллекций для начинающих — в пособии Java Core (темы 08–09, 11); модель памяти и блокировки — в Java Concurrency; раскладка объектов, упаковка и слабые ссылки — в пособии «JVM изнутри» (темы 10, 15).
