Стримы поверх коллекций и Collectors

Стрим — не коллекция, а ленивый конвейер поверх сплитератора источника: элементы по одному проходят все операции, а работа начинается только с терминальной операции. Трассировщик покажет порядок вызовов и короткое замыкание limit/findFirst, а конструктор коллекторов — как собирать результаты в нужные коллекции: toMap с дубликатами, groupingBy с подчинёнными коллекторами, partitioningBy, teeing.

17.1Как течёт конвейер

Трассировка: List.of(5, 2, 8, 1, 9, 4, 7)

Внутри: каждая промежуточная операция — стадия AbstractPipeline; терминальная операция «склеивает» стадии в цепочку Sink-ов и вызывает spliterator.forEachRemaining(sink). Для операций с коротким замыканием используется tryAdvance с проверкой отмены. Флаги сплитератора (SIZED, DISTINCT, SORTED) позволяют пропускать лишнюю работу.

17.3Практические правила

  • Не изменяйте источник из лямбд стрима (CME или неопределённое поведение) и не используйте внешнее изменяемое состояние (list.add в forEach параллельного стрима — гонка). Собирайте коллектором.
  • Цикл против стрима: для простой итерации с побочными эффектами, ранним выходом с возвратом, проверяемыми исключениями — обычный for. Стримы — для преобразований и агрегаций.
  • Примитивные стримы (IntStream, mapToInt, sum()) избегают упаковки.
  • Stream.toList() (неизменяемый, допускает null) против Collectors.toList() — тема 14.
  • Map.entrySet().stream() для работы с картами; обратно — toMap(Map.Entry::getKey, Map.Entry::getValue).
  • Java 22+: Stream Gatherers (gather(Gatherers.windowFixed(3)), финальные в Java 24) — свои промежуточные операции: окна, сканирование, свёртки с состоянием.

17.4Самопроверка

Сколько раз вызовется filter в List.of(1..1_000_000).stream().filter(x -> x > 10).findFirst()?

  • 1 000 000
  • 0
  • 11 — до первого подходящего элемента
  • 10
Короткое замыкание и обработка по одному элементу.

Что сделает toMap(k, v) при дублирующемся ключе?

  • Бросит IllegalStateException: Duplicate key
  • Оставит первое значение
  • Оставит последнее значение
  • Соберёт значения в список
Нужна merge-функция третьим аргументом.

Почему .sorted().limit(1) не быстрее полной сортировки?

  • limit игнорируется
  • sorted — терминальная операция
  • limit работает до sorted
  • sorted — барьер: должна получить все элементы до выдачи первого
Для минимума — min(); для top-k — куча.

Какая карта и какие коллекции значений у groupingBy(f) по умолчанию?

  • TreeMap и TreeSet
  • HashMap и списки (toList)
  • LinkedHashMap и ArrayList с гарантией
  • ConcurrentHashMap
Для порядка групп передайте фабрику карты.
Почему стрим нельзя использовать дважды?

Стрим — одноразовый конвейер над сплитератором источника, который потребляется при обходе (и может быть одноразовым по природе: файл, сеть, генератор). После терминальной операции стадии помечаются использованными — повторный вызов бросает IllegalStateException. Нужен повторный обход — создайте стрим заново из коллекции (Supplier<Stream>) или соберите результат в коллекцию.
