Что не так с new HashMap<>(map.size()) для копии большой карты?

  • Ничего
  • Конструктор не принимает int
  • Ёмкость меньше нужной для порога 0.75 — при копировании произойдёт лишний resize
  • Это создаст TreeMap
new HashMap<>(map) сам вычисляет ёмкость правильно.

Какая операция безопасна внутри for-each по ArrayList?

  • list.set(i, x) — замена значения
  • list.add(x)
  • list.remove(x)
  • list.clear()
set не меняет modCount.
