java.util.concurrent: полное руководство изнутри

Справочник-учебник по всему пакету java.util.concurrent: от инструкций процессора и режимов памяти VarHandle через атомики, LockSupport и AbstractQueuedSynchronizer к блокировкам, синхронизаторам, пулам потоков, ForkJoinPool, CompletableFuture, очередям, Flow API и структурной конкурентности. У каждого класса разобрано устройство по исходникам JDK и есть симулятор, где видно, что происходит с состоянием, очередями и потоками при каждой операции.

Senior

Как работать с пособием

  1. Читайте исходники пакета параллельно с темами: AbstractQueuedSynchronizer, ReentrantLock, ThreadPoolExecutor, CompletableFuture — с подробными комментариями Дага Ли.
  2. Прокручивайте симуляторы в разном порядке событий — конкурентность и есть множество возможных расписаний.
  3. Проверяйте jcstress и JMH: лакмус-тесты (тема 03) и замеры масштабируемости (темы 02, 06) на своём железе, особенно на ARM.
  4. Решайте задачи темы 24 до чтения решений.
Связь с соседними пособиями Основы потоков, Java Memory Model, synchronized, виртуальные потоки, диагностика и паттерны — в пособии Java Concurrency; здесь — углублённое устройство каждого класса пакета. Конкурентные коллекции (ConcurrentHashMap, CopyOnWrite) — в пособии «Коллекции изнутри», тема 18; safepoints и устройство мониторов в JVM — в «JVM изнутри», тема 18.
