24.1Задачи

1. Объединение одинаковых запросов (request coalescing): если 100 потоков одновременно просят профиль пользователя 42, в БД должен уйти один запрос.
private final ConcurrentHashMap<Long, CompletableFuture<Profile>> inFlight = new ConcurrentHashMap<>();
CompletableFuture<Profile> load(long id) {
    CompletableFuture<Profile> f = inFlight.computeIfAbsent(id,
        k -> CompletableFuture.supplyAsync(() -> repo.find(k), io));   // функция лишь СОЗДАЁТ future — быстро, под блокировкой корзины
    f.whenComplete((p, ex) -> inFlight.remove(id, f));               // убрать после завершения (remove(key, value)!)
    return f;
}

Важно: долгая работа не внутри computeIfAbsent (там только создание future), удаление — условное, чтобы не снести более новый запрос.

2. Ограничитель частоты «не больше N операций в секунду» без блокировок.
final class TokenBucket {
    private final long capacity, nanosPerToken;
    private final AtomicLong state;     // время, «до которого» токены израсходованы (virtual scheduling)
    TokenBucket(long perSecond) { capacity = perSecond; nanosPerToken = 1_000_000_000L / perSecond; state = new AtomicLong(System.nanoTime()); }
    boolean tryAcquire() {
        while (true) {
            long now = System.nanoTime(), cur = state.get();
            long base = Math.max(cur, now - capacity * nanosPerToken);   // не копить больше capacity
            long next = base + nanosPerToken;
            if (next > now) return false;                                // токенов нет
            if (state.compareAndSet(cur, next)) return true;
        }
    }
}

Один CAS-цикл, состояние — одно число. Для распределённого ограничения — Redis.

3. Кэш «читается постоянно, обновляется раз в минуту целиком».

volatile Map<K, V> snapshot = Map.copyOf(load()); читатели — просто чтение ссылки; ScheduledExecutorService раз в минуту строит новую карту и присваивает (copy-on-write). 4. Дебаунс: вызывать сохранение черновика не чаще раза в 500 мс после последнего изменения.
private final ScheduledExecutorService ses = Executors.newSingleThreadScheduledExecutor();
private final AtomicReference<ScheduledFuture<?>> pending = new AtomicReference<>();
void onChange(Draft d) {
    ScheduledFuture<?> next = ses.schedule(() -> save(d), 500, TimeUnit.MILLISECONDS);
    ScheduledFuture<?> prev = pending.getAndSet(next);
    if (prev != null) prev.cancel(false);        // отменить предыдущее отложенное сохранение
}
5. Параллельная сортировка слиянием на ForkJoinPool.
final class MergeSort extends RecursiveAction {
    final int[] a, tmp; final int lo, hi;
    MergeSort(int[] a, int[] tmp, int lo, int hi) { this.a = a; this.tmp = tmp; this.lo = lo; this.hi = hi; }
    protected void compute() {
        if (hi - lo < 4096) { Arrays.sort(a, lo, hi); return; }
        int mid = (lo + hi) >>> 1;
        invokeAll(new MergeSort(a, tmp, lo, mid), new MergeSort(a, tmp, mid, hi));   // fork + compute + join
        merge(a, tmp, lo, mid, hi);
    }
}
ForkJoinPool.commonPool().invoke(new MergeSort(arr, new int[arr.length], 0, arr.length));
// на практике — Arrays.parallelSort(arr)
6. Остановить пул воркеров, читающих BlockingQueue, без потери уже принятых задач.

Перестать принимать новые задачи (флаг/закрыть вход), положить в очередь по одному poison pill на каждого воркера (они встают после реальных задач — FIFO), дождаться завершения (CountDownLatch или join/awaitTermination с таймаутом), по истечении — interrupt. Если воркеры — ExecutorService: shutdown() + awaitTermination, затем shutdownNow().

ConcurrentHashMap<String, LongAdder> + computeIfAbsent(endpoint, k -> new LongAdder()).increment(): конкуренции нет ни на карте (после создания ключа — только чтение), ни на счётчике (ячейки LongAdder). Чтение — sum() при выгрузке метрик.
